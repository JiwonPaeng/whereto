# SKY 3개 대학 Program 작성 워크시트

> **이건 데이터가 아니라 작업지시서다.** 채워주시면 시드 SQL로 옮긴다.
>
> §11.2가 요구하는 공식 홈페이지 대조는 직접 하셔야 한다. 추측으로 채운 학과명이
> DB에 들어가고 그 위에 투표가 쌓이면 되돌리기 어렵다.

## 작성 방향 (D-006으로 뒤집힘)

**대학 홈페이지의 학과 목록을 그대로 옮겨 적고, 각 줄에 표준 학과를 고른다.**

이전 버전은 표준 학과에서 출발해 대학별 명칭을 채우는 방식이었는데, 그러면 한 대학에
컴퓨터공학과와 인공지능학과가 같이 있는 경우가 들어갈 자리가 없었다. 스키마도 고쳤다 —
이제 **한 대학에 같은 표준 학과를 가진 Program 이 여럿 있어도 된다.**

## 채우는 법

| 대학 | 실제 학과명 | 표준 학과 |
|---|---|---|
| 고려대 | 컴퓨터학과 | 컴퓨터공학 |
| 고려대 | 인공지능학과 | 컴퓨터공학 |
| 연세대 | 인공지능학과 | 컴퓨터공학 |

- **실제 학과명** = `programs.display_name`. 홈페이지 표기 그대로. 화면에 이대로 나온다
- **표준 학과** = 아래 목록에서 고른다. 매칭·필터의 기준이 된다 (§9.1)
- 위 예시처럼 **같은 표준 학과가 반복돼도 된다**
- 맞는 표준 학과가 없으면 **새 이름을 적고 `[신규]`** 라고 표시. 계열도 함께 적어주시면 `majors` 에 추가한다
- 학부 신입학 모집이 없는 곳(전문대학원만 있는 경우)은 **적지 않는다**

## 고를 수 있는 표준 학과 (현재 45개)

| 계열 | 표준 학과 |
|---|---|
| **인문** | 국어국문 · 영어영문 · 사학 · 철학 |
| **사회** | 심리학 · 사회학 · 정치외교 · 행정학 · 경제학 · 경영학 · 통계학 · 미디어커뮤니케이션 · 법학 |
| **자연** | 수학 · 물리학 · 화학 · 생명과학 · 식품영양학 |
| **공학** | 컴퓨터공학 · 전기전자공학 · 기계공학 · 화학공학 · 신소재공학 · 산업공학 · 토목환경공학 · 건축학 · 항공우주공학 |
| **의약** | 의학 · 치의학 · 한의학 · 약학 · 수의학 · 간호학 |
| **사범** | 국어교육 · 영어교육 · 수학교육 · 사회교육 · 과학교육 · 체육교육 · 초등교육 |
| **예체능** | 시각디자인 · 산업디자인 · 음악 · 연극영화 · 스포츠과학 |

**이 목록은 자란다.** 대학을 추가할 때마다 새 표준 학과가 생기는 게 정상이다 (D-006).
지금 없다고 억지로 끼워 맞추지 말고 `[신규]`로 적어주시는 편이 낫다 —
억지 매핑은 §5.4 매칭 품질을 직접 떨어뜨린다.

## 판단이 필요한 것 (같이 정할 부분)

작성하시다가 아래에 해당하면 알려주세요. 임의로 정하면 2단계 확장 때 17개 대학에 그대로 번집니다.

**1. 잘게 쪼개진 계열**
과학교육이 물리교육/화학교육/생물교육/지구과학교육으로, 음악이 작곡/성악/기악으로 나뉘어 있는 경우.
표준 학과를 쪼갤지, 하나로 묶고 `display_name` 으로만 구분할지 정해야 합니다.

**2. 계열 소속이 대학마다 다른 학과**
`faculty_group` 은 `majors` 에 있는 **대학 무관 단일 값**이라 하나를 골라야 합니다. 현재 제 임의 분류:

| 표준 학과 | 현재 | 갈리는 이유 |
|---|---|---|
| 통계학 | 사회 | 서울대는 자연과학대학, 고려대는 정경대학 |
| 심리학 | 사회 | 대학에 따라 사회과학/자연과학 양쪽 |
| 식품영양학 | 자연 | 생활과학대학 소속이 많음 |

**3. 자유전공·광역 모집단위**
학과가 아니라 계열 단위로 뽑는 모집단위(자유전공학부 등)를 Program 으로 넣을지.
넣는다면 표준 학과를 새로 만들어야 합니다.
